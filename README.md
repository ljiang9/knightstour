# knightstour

终端骑士周游求解器: 在棋盘上找到马走遍每个格子恰好一次的路线。

## 用法

```bash
python -m knightstour                 # 8x8, 从 A1 出发找周游
python -m knightstour --size 6        # 6x6
python -m knightstour --start D4      # 指定起点
python -m knightstour --closed        # 要求闭合周游(终点能一步跳回起点)
python -m knightstour --seed 42       # 固定随机种子, 结果可复现
```

输出为带步数的编号棋盘, 如 `1` 为起点, `64` 为终点。

## 算法

**Warnsdorff 启发式** (1823): 每次走子时, 在所有合法候选落点中选择"后续可选落点最少"(出度最小) 的一个。
出度相同则随机打散, 失败时整体重试 (最多 200 次)。

- 8x8 通常一次尝试即成功, 远快于 2 秒。
- 该启发式不是完备算法: 奇数边长棋盘(如 5x5) 偶尔会失败, 换 `--seed` 重试即可。
- `--closed` 对偶数棋盘一般可行; 奇数棋盘不存在闭合周游(黑白格数不等), 请勿强求。

## 已知局限

- 纯启发式, 不保证找到解; 失败时退出码 1 并提示换种子重试。
- 棋盘限制 4–10, 无交互式手动游玩模式。
- 纯标准库, 无第三方依赖。
